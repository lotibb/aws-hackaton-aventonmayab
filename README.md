# Aventón Mayab

Aplicación de carpool y Smart Parking para la Universidad Anáhuac Mayab.

## Módulos

- [`backend/smartparking/`](backend/smartparking/): backend TypeScript de la función de Smart Parking. Incluye API de zonas y sesiones de estacionamiento, infraestructura AWS CDK, pruebas e instrucciones de despliegue e integración con el frontend TSX.

Consulta el [README de Smart Parking](backend/smartparking/README.md) para instalar dependencias, verificar el módulo y desplegarlo. La autenticación depende del Cognito provisto por el equipo de login.
